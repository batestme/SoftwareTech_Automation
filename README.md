## Reflection

### How can I ensure that my code, program, or software is functional and secure?

I can make sure my code works by testing it often and not waiting until the end. In this course, unit tests helped me catch mistakes early and made it easier to fix problems. I also learned that reading the requirements closely matters because missing one small detail can cause issues later. For security, checking user input and writing clean code are important. Even simple programs should be built carefully.

### How do I interpret user needs and incorporate them into a program?

I start by looking at the requirements and figuring out what the user actually wants the program to do. Then I break it into smaller parts and build each part from there. In this class, the customer wanted contact, task, and appointment services with certain limits and rules. I used those requirements to guide how I wrote the classes and tests.

### How do I approach designing software?

I usually start by planning before I code. I think about what classes are needed, what information they should store, and what methods they need. After that, I build one part at a time and test along the way. I think keeping the design simple is important because it makes the program easier to understand and easier to fix later.
